# FlowSplice PTY visual study — brand inputs

- Existing icon: ../../assets/brand/pty/pty-icon.png and pty-mark.png. Preserve the mint terminal ribbon; no brand replacement is proposed.
- Reference: the owner's September 8 screenshot of the working macOS client. It establishes the current usability problem, not the target visual style.
- Product: a private FlowSplice PTY client whose new design must manage multiple independently authorized Homes simultaneously, each with named persistent tmux sessions. This supersedes the initial single-Home design assumption; the current implementation is still single-Home.
- Typography assumption: platform-native interface typography and a legible monospace terminal. Practical native-tool conventions take precedence over decorative display typography.
- Three exploratory palettes: charcoal with mint, light neutral native chrome with a dark terminal, warm graphite with restrained mint. These are design proposals, not accepted settings.
- Real third-party screenshots were inspected through Termius official articles. Termius branding will not appear inside proposed FlowSplice screens.
- No photography or decorative illustration is needed. Product UI and the existing icon are the visual content.
