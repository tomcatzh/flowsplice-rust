# FlowSplice 0.4.1

FlowSplice 0.4.1 fixes a TCP Carrier backpressure deadlock in the shared Home and
Travel runtimes. A full Flow event queue could stop a Carrier from servicing its
outgoing queue, heartbeat, or cancellation. A Flow waiting on the outgoing queue
could then stall until the runtime was restarted.

The Carrier now waits for event-queue capacity while continuing to service outgoing
frames and heartbeats. It retains at most one pending inbound event and preserves
event order. Cancellation and network changes can interrupt blocked I/O. Closing a
Carrier releases its socket, outgoing receiver, and resource permits before waiting
to notify the Flow.

## Affected products and SDKs

The fix is shared by generic Home/Travel applications, native Travel clients on
Android, iOS/iPadOS and macOS, and the private PTY products. It is included in the
`flowsplice-home-core` and `flowsplice-travel-core` SDKs. Server and Relay receive
the coordinated version update; their forwarding loops are not the source of this
deadlock. Existing configuration, certificates and identities are retained.

## Regression coverage

New tests exercise full event and outgoing queues, ordered delivery, heartbeat
progress, cancellation, and releasing connection permits before close notification.
Real TLS regressions cover stalled I/O and repeated network changes with a fixed
connection budget. The original implementation fails the targeted regressions;
the corrected implementation passes them.

These tests establish the defect and its correction. They do not establish a unique
cause for a historical device slowdown whose process state was lost on restart.

## Distribution

This is a source-only release. Deployment-specific native installers are built
privately, and no crates.io packages or private binary assets are published.
Git consumers should select `tag = "0.4.1"`, update their FlowSplice dependencies
and commit the resulting lockfile. The earlier `0.4` tag remains unchanged.

See the [SDK guide](../../crates/README.md),
[private Travel packaging](../PRIVATE_TRAVEL_PACKAGING.md), and
