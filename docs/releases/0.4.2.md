# FlowSplice 0.4.2

FlowSplice 0.4.2 bounds additional UDP and control-plane waits found while reviewing
the TCP Carrier fix in [0.4.1](0.4.1.md).

## Fixes

- Travel UDP application delivery now uses the configured UDP idle timeout.
  Runtime shutdown and network changes interrupt the entire association, including
  carrier opening and blocked writes. Datagram ordering and empty payloads are
  preserved; only delivered downloads are counted.
- Server Relay sessions return immediate enrollment errors to their own writer.
  They no longer wait to enqueue replies into a queue that only the same task can
  consume. Initial authorization updates also bypass that queue, with a generation
  check that prevents older queued snapshots from following a newer snapshot.
- Relay requests share one deadline for queue admission and the response. Their
  pending registrations are removed on completion, timeout, disconnect or caller
  cancellation. Duplicate request identifiers do not overwrite existing waiters.
- Server forwarding and Home issuer dispatch use existing request deadlines.
  Expired replies are ignored, mismatched responders cannot consume another
  request, and a congested destination does not disconnect an unrelated healthy
  control session. Pending-work locks are released before network replies.
- Relay management listeners can react to network changes while all connection
  permits are occupied. Route readiness and session release also have bounded
  waits, and unsuccessful route setup releases its admission resources.
- Carrier documentation and tests now make the existing 10-second frame-write
  deadline explicit. A receive timeout with pending local event delivery reports
  that condition instead of attributing it solely to the peer heartbeat.

## Scope and verification

The shared runtime fixes reach the Home/Travel SDKs, generic native clients and
private PTY applications on Android, iOS/iPadOS and macOS. Server and Relay contain
control-plane fixes in this release. Configuration, certificates, identities and
public socket interfaces retain their existing formats.

Regression coverage includes bounded queue saturation, ordered and empty UDP
datagrams, blocked-write cancellation, pending-registration cleanup, late replies,
authorization snapshot ordering, and listener admission during network changes.
The release workflow additionally runs the workspace tests, strict lint checks,
real TLS regressions, standalone SDK checks and current-version end-to-end tests.

The original Magic V5 slowdown has no surviving pre-restart process trace. These
reproduced defects and regression tests do not establish its unique historical cause.

## Distribution

This is a source-only release. Native installers and deployment packages are built
privately; no crates.io packages or private binary assets are published.
Git consumers should select `tag = "0.4.2"`, update their FlowSplice dependencies,
and commit the resulting lockfile. Earlier tags remain unchanged.

See the [SDK guide](../../crates/README.md) and
[private Travel packaging](../PRIVATE_TRAVEL_PACKAGING.md).
