# FlowSplice Brand Assets

Direction A — Continuous S is the canonical FlowSplice mark.

- `flowsplice-icon.svg`: full-color icon on the Deep Ink field.
- `flowsplice-symbol.svg`: transparent Flow Mint symbol.
- `flowsplice-monochrome.svg`: single-color symbol for tinted surfaces.

Run `python3 scripts/generate-brand-icons.py` from the repository root after
changing a master. The script exports browser, home-screen, and legacy Android
raster assets while preserving the approved 108-unit geometry.
